# walkthrough

A skill for explaining how something works with a step-through visual page. Each chapter is one diagram that changes
with every step, the reader drives it with Back and Next, a short caption carries the reasoning, and a small example's
numbers really compute. The infographic skill tells a story at a glance; this one goes a level deeper into the
mechanism.

```
/plugin install walkthrough@yuvalsarel1
```

Then ask how something works, or type `/walkthrough`. `skills/walkthrough/assets/stepper.html` is a working template
with the stepper engine and one sample chapter.
